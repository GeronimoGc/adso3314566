01-Emmet

Work Flow - Markup & Styling

Nesting >

ejemplo:

ul>li>a 🔂

Resultado

<ul> <li><a href=""></a></li> </ul>

Sibling +

ejemplo:

section+header+nav 🔂

Resultado

<section></section> <header></header> <nav></nav>

Repeat *

ejemplo:

ul>li*3 🔂

Resultado

<ul> <li></li> <li></li> <li></li> </ul>

classes .

ejemplo:

div.contenedor 🔂
.contenedor2 🔂

Resultado

<div class="contenedor"></div>

Id #

ejemplo:

nav#menu 🔂

Resultado

<nav id="menu"></nav>

text {}

ejemplo:

div{Lorem Ipsum Dolor} 🔂
a{Click Aquí}

Resultado

<div>Lorem Ipsum Dolor</div> <a href=“”>Click Aquí</a>

Custom Atr []

ejemplo:

a[href=www.google.com] 🔂

Resultado

<a href="www.google.com"></a>

Numbering $

ejemplo:

ul>li.num$*3 🔂
section>article.sec$$$*3 🔂

Resultado

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

invert numbs @-

ejemplo:

ul>li.num$@-*3 🔂

Resultado

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

Base numb @n

ejemplo:

ul>li.num$@3*4 🔂

Resultado

<ul> <li class="num3"></li> <li class="num4"></li> <li class=“num5"></li> <li class=“num6"></li> </ul>

Leveling ^

ejemplo:

section>article>div^p 🔂

Resultado

<section> <article> <div></div> </article> <p></p> </section>

Grouping ()

ejemplo:

(header>nav)(section>article) 🔂

Resultado

<header> <nav></nav> </header> <section> <article></article> </section>

Dummy Text ( Lorem )

ejemplo:

lorem 🔂
lorem20 🔂
lorem *5

Document HTML

ejemplo:

html:xs 🔂 -- Documento xhtml 1.0 Stric
html:xt 🔂 -- Documento xhtml 1.0 Transitional
html:4s 🔂 -- Documento xhtml 4.01 Stric
html:4t 🔂 -- Documento xhtml 4.01 Transitional
html:5 🔂 -- Documento xhtml 5

Meta TAGS

ejemplo:

meta:vp —— <meta name="viewport" content=“width=device-width...">
